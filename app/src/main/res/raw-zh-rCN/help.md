# 开始

打开播放列表。添加 Xtream 登录、M3U URL、M3U 文件或 Stalker 门户(地址和 MAC)。Xtream 和 Stalker 自带节目单。注明了节目单的 M3U 也自带;否则请添加节目单 URL。把完整的 Xtream 面板链接粘贴为服务器,会自动填入用户名和密码。

# 主屏幕

搜索在最上方。它搜索栏目中的所有分组,完全匹配的名称排在前面。旁边的语音可以用说话填写。返回会清空。

下方:直播电视、电影、剧集。然后是播放列表、正在播出、搜索节目单、录制、更多。

分组在左边,列表在右边。两者都有标题。选择分组后会转到列表。

遥控器或键盘上的数字键可直接跳到该频道号。

# 更多

上一个频道、最近观看、转到频道号、刷新播放列表、刷新节目单、账户、设置、检查更新、帮助。

# 项目

激活即可播放。剧集会打开其分集。

操作菜单:用其他应用播放、收藏、详情、节目单、录制或停止录制、下载。不用 TalkBack 时:长按或菜单键。

# 节目单

正在播出列出所有正在播放的节目。频道节目单可以播放标为可回看的过去节目,并预约将来的节目。搜索节目单可以找到即将播出的节目。

# 播放器

按钮:暂停、音轨、字幕、录制、投屏、全屏、关闭。按键:播放/暂停,A 切换音轨,S 字幕,F 全屏。

全屏会隐藏按钮。点按、返回、确定或 F 可以让它们回来。

频道有口述影像时会自动选择。你选择的音轨会按频道记住。

字幕显示在视频下方并被朗读,除非在设置中关闭了朗读字幕。

节目变化时,播放器会播报正在播出的节目。设置中的播报决定播放器说多少。

断开的直播会自动重新连接。

# 录制

保存在 Movies/AccessibleIPTV。正在录制的排在最前;激活某项即可停止。

预约录制会在结束后多录 2 分钟,重启后依然有效。前后的分钟数可在设置中修改。

提前结束的回看下载会重新下载。

# 设置

导出设置会把播放列表、登录信息、收藏和选项保存到文件。导入设置可在本机或其他设备上加载该文件。

# 更新

应用每天检查一次新版本。更多、检查更新会立即检查。Android 每次安装都会要求确认。

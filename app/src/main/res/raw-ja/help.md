# はじめに

プレイリストを開きます。Xtream のログイン、M3U URL、M3U ファイル、または Stalker ポータル (アドレスと MAC) を追加します。Xtream と Stalker は自分の番組表を持っています。番組表を指定している M3U も同じです。そうでなければ番組表の URL を追加します。Xtream パネルのリンク全体をサーバー欄に貼り付けると、ユーザー名とパスワードが入ります。

# メイン画面

検索は一番上です。セクション内のすべてのグループを検索し、完全に一致する名前が先に出ます。隣の音声で話して入力できます。戻るで消えます。

その下: ライブTV、映画、シリーズ。続いてプレイリスト、放送中、番組表を検索、番組表、録画、その他。

グループは左、リストは右です。どちらにも見出しがあります。グループを選ぶとリストに移ります。

リモコンやキーボードの数字キーで、その番号のチャンネルに移ります。

# その他

前のチャンネル、最近見たもの、チャンネル番号へ移動、プレイリストを更新、番組表を更新、アカウント、設定、アップデートを確認、ヘルプ。

# 項目

実行すると再生します。シリーズはエピソードを開きます。

アクションメニュー: お気に入り、詳細、番組表、録画または録画停止、ダウンロード。TalkBack なしでは長押しかメニューキー。

# 番組表

放送中は、いま放送しているものをすべて表示します。チャンネルの番組表は、見逃しの印が付いた過去の番組を再生し、これからの番組を予約します。番組表を検索は、これからの番組を探します。

# プレーヤー

ボタン: 一時停止、音声、字幕、録画、キャスト、全画面、閉じる。キー: 再生/一時停止、A で音声、S で字幕、F で全画面。

全画面ではボタンが隠れます。タップ、戻る、OK、F で戻ります。

チャンネルに音声解説があれば選ばれます。選んだトラックはチャンネルごとに記憶されます。

字幕は動画の下に表示され、読み上げられます。設定で字幕を読み上げるがオフなら読み上げません。

番組が変わると、プレーヤーが放送中の番組を伝えます。設定の読み上げで、プレーヤーがどれだけ話すかを選べます。

途切れたライブ配信は自動で再接続します。

端末ごとにプロバイダーのストリームを1つだけ使用できます。同じライブTSストリームの視聴、キャスト、録画は1つのストリームを共有します。別のストリームは、現在のストリームを停止するまで開始できません。他のアプリの接続数は制限できないため、外部プレーヤーには引き渡せません。

# 録画

Movies/AccessibleIPTV に保存されます。録画中のものが先頭に並び、実行すると停止します。

予約録画は終了後 2 分まで続き、再起動しても残ります。前後の分数は設定で変えられます。

途中で終わった見逃しのダウンロードは、もう一度取得します。

HLSリクエストは1つずつ処理されます。ダウンロード中はストリームを他の用途に使えません。

# 設定

設定をエクスポートは、プレイリスト、ログイン、お気に入り、オプションをファイルに保存します。設定をインポートは、その端末または別の端末で読み込みます。

# アップデート

アプリは 1 日 1 回新しいバージョンを確認します。その他、アップデートを確認ですぐに確認します。Android はインストールのたびに確認を求めます。

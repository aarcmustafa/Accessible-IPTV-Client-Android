# Начало

Откройте Плейлисты. Добавьте вход Xtream, URL M3U, файл M3U или портал Stalker (адрес и MAC). Xtream и Stalker приносят свою программу. M3U, где указана программа, тоже приносит её; иначе добавьте URL программы. Полная ссылка панели Xtream, вставленная как сервер, заполняет логин и пароль.

# Главный экран

Поиск вверху. Он ищет во всех группах раздела; точные названия идут первыми. Кнопка Голос рядом заполняет его голосом. Назад очищает его.

Ниже: Прямой эфир, Фильмы, Сериалы. Затем Плейлисты, Сейчас в эфире, Поиск по программе, Программа, Записи, Ещё.

Группы слева, список справа. У обоих есть заголовки. Выбор группы переводит к списку.

Цифровые кнопки пульта или клавиатуры переключают на канал с этим номером.

# Ещё

Предыдущий канал, Недавно смотрели, Перейти к номеру канала, Обновить плейлисты, Обновить программу, Аккаунт, Настройки, Проверить обновления, Справка.

# Элементы

Активируйте, чтобы смотреть. Сериал открывает свои серии.

Меню действий: открыть в другом приложении, избранное, подробно, программа, записать или остановить запись, скачать. Без TalkBack: долгое нажатие или кнопка Меню.

# Программа

Сейчас в эфире показывает всё, что идёт. Программа канала воспроизводит прошедшие передачи с пометкой архив и планирует будущие. Поиск по программе находит будущие передачи.

# Плеер

Кнопки: Пауза, Звук, Субтитры, Запись, Трансляция, Во весь экран, Закрыть. Клавиши: воспроизведение/пауза, A для звука, S для субтитров, F для полного экрана.

Полный экран скрывает кнопки. Касание, Назад, OK или F возвращают их.

Тифлокомментарий выбирается, если он есть на канале. Выбранная дорожка запоминается для каждого канала.

Субтитры показываются под видео и озвучиваются, если в Настройках включено Озвучивать субтитры.

Когда меняется передача, плеер говорит, что сейчас в эфире. Настройки, Объявления задают, сколько говорит плеер.

Оборвавшийся прямой эфир переподключается сам.

# Записи

Сохраняются в Movies/AccessibleIPTV. Идущие записи стоят первыми; активируйте запись, чтобы остановить её.

Запланированные записи идут ещё 2 минуты после конца и переживают перезагрузку. Минуты до и после меняются в Настройках.

Скачивание из архива, оборвавшееся раньше времени, повторяется.

# Настройки

Экспорт настроек сохраняет плейлисты, входы, избранное и параметры в файл. Импорт настроек загружает такой файл на этом или другом устройстве.

# Обновления

Приложение ищет новую версию раз в день. Ещё, Проверить обновления проверяет сразу. Android просит подтвердить каждую установку.
